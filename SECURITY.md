# Security disclosures

The maintained development series is 0.1.x. Report security concerns privately to the repository owner using the hosting provider’s private vulnerability reporting feature when available. Include the commit or archive version, reproduction steps against synthetic data, and the expected and observed impact. Strip credentials, access tokens, and customer data from the report.

The demo realm and its password grant are intended for an isolated local stack. See the [threat model](docs/threat-model.md), [acceptance report](docs/acceptance.md), and [deployment hardening guide](docs/deployment-hardening.md) for validation scope and residual risks.
